# Sources: Why aeroplane windows are never square

Note: the popular story that "square windows" alone brought down the Comet is a simplification. The Comet 1's
windows already had small corner radii; the test fuselage failed near an escape-hatch cut-out. The script
says "near the corner of an opening in the cabin" for that reason.
